# Hello Menu Bar App

A simple macOS app that displays "hello" in the menu bar.

## Building the App

You can build the app using the provided shell script:

```bash
chmod +x compile.sh
./compile.sh
```

This will create a `HelloMenuBar.app` bundle that you can run by double-clicking on it in Finder or using:

```bash
open HelloMenuBar.app
```

## Developing in VSCode

Open this folder in VSCode to edit the Swift files. Use the terminal in VSCode to compile and run the app.
